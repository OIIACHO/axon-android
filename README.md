# AXON

Умный менеджер подписок для Android (концепт, v0.1.0-alpha).

Главная идея: при каждом обновлении подписки — ручном или автоматическом при добавлении новой — из списка узлов удаляются:

- **дубли** — одинаковый протокол / хост / порт / креденшл;
- **небезопасные узлы** — без TLS (`security=none`), VMess с `scy=none`, устаревшие SS-шифры (rc4, CFB, chacha20 без poly1305), `allowInsecure=1`;
- **битые** — некорректный хост, порт или отсутствующий креденшл.

## Стек

Kotlin 1.9.24, Jetpack Compose (Material 3, тёмная тема), без внешних зависимостей парсинга — всё своё: парсер `vless://`, `vmess://`, `trojan://`, `ss://`, движок гигиены, TCP-проба узлов, самотест из 10 встроенных узлов.

## Сборка APK

APK собирает GitHub Actions:

- [Actions](https://github.com/OIIACHO/axon-android/actions) → артефакт `AXON-debug`
- [Releases](https://github.com/OIIACHO/axon-android/releases) → тег `v0.1.0-alpha`

Локально: Gradle 8.7, JDK 17 → `gradle assembleDebug`.

## Самотест

Вкладка «Самотест» в приложении прогоняет 10 встроенных узлов через парсер и движок гигиены.

Ожидание: **10 получено → 4 оставлено, 1 дубль, 4 небезопасных, 1 битый.**
